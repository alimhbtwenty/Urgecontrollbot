# Urgecontrollbot

بات تلگرامی ثبت خودکار ساعت ورود/خروج همراه با موقعیت مکانی.

## نحوه کار

1. `/start` رو به بات بزن.
2. یکی از دکمه‌های `🟢 ثبت ورود` یا `🔴 ثبت خروج` رو بزن.
3. دکمه `📍 ارسال موقعیت مکانی` رو بزن تا لوکیشن فعلیت ارسال بشه.

همین! بات زمان، نام و موقعیتت رو ثبت می‌کنه و (در صورت تنظیم بودن) برای گروه/چت همکارهات می‌فرسته.

## نصب و اجرا

```bash
pip install -r requirements.txt
```

یه فایل `.env` بساز:

```
BOT_TOKEN=توکن بات از BotFather
TARGET_CHAT_ID=آیدی چت یا گروه همکارها (اختیاری)
```

برای گرفتن آیدی گروه همکارها: بات رو به اون گروه اضافه کن و دستور `/chatid` رو داخل گروه بزن.

اجرا:

```bash
python main.py
```
