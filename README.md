# Urgecontrollbot

بات تلگرامی ثبت ساعت ورود/خروج به همراه اسم مکان.

## نحوه کار

1. `/start` رو به بات بزن.
2. یکی از دکمه‌های `🟢 ثبت ورود` یا `🔴 ثبت خروج` رو بزن.
3. اسم مکان رو از لیست انتخاب کن، یا با دکمه `➕ مکان جدید` یه مکان تازه اضافه کن (از این به بعد توی لیست می‌مونه).
4. بات یه متن آماده به فرمت پیام‌های واتساپ می‌ده (توی یه باکس کد که با یه لمس کپی می‌شه) — همون رو بفرست تو گروه واتساپ همکارها.

فرمت خروجی مثل نمونه‌های زیره:

```
سلام
شنبه
۱۴۰۵/۰۶/۱۴
ورود به مائده قوطی
۹:۵۰
```

پیام‌های بعدی همون روز دیگه سلام/تاریخ نداره، فقط `ورود به {مکان}` یا `خروج` و ساعت.

## نصب و اجرا

```bash
pip install -r requirements.txt
```

یه فایل `.env` بساز:

```
BOT_TOKEN=توکن بات از BotFather
```

اجرا:

```bash
python main.py
```
